# Native research replay example

Open this directory in Studio or configure its CMake project. `strategy.c` is a complete trusted C strategy. `main.c` runs the fixed example, a latency comparison or the strict six-column CSV loader. Results go to stdout. The `client` subdirectory builds only the application against an installed SDK.

The public guide is `../../docs/learning/research-replay.html`. No model here sends a broker order. Keep real execution under the separate Framework risk and order authorities.
