# A Notes release needs more than one passing test

`review_notes_release.c` is the complete memory-only example. It creates a fictional five-item contract and one Linux receipt. The checker retains four blockers, including the Windows installed-GUI journey.

The example uses the same public API and distribution owner as the production tool. It does not open a window, check an actual Notes binary, authenticate a publisher or publish a release. The receipts must not be copied into a real evidence book.

The `client` directory is a separate project. Configure it against an installation of the focused SDK using `-DCMAKE_PREFIX_PATH=<install>`. It proves public-header and link usability for this subset only, not all of Framework's installed SDK.
