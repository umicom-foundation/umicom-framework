# Umicom Framework GTK4 Component Library

`Umicom::ui_gtk4` remains optional. When enabled, it maps semantic component specifications to reusable GTK4 widgets. Applications may also call the explicit GTK4 component constructors from `umicom/ui/gtk4/components.h`.

The component library is intentionally not a one-to-one rename of GTK. Shared Umicom behaviour and product reuse justify a component entering Framework.
