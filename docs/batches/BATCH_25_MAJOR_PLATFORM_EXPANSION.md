# Batch 25 — Major Framework Platform Expansion

Created by: Sammy Hegab  
Organisation: Umicom Foundation  
Licence: MIT

This batch completes the previously missed unified-workbench build integration and adds reusable models for list/tree/selection, docking/tabs/panels, command/context surfaces, resource navigation, server-driven frontend composition, product marketplace/update state, advanced chart interaction, visual-designer authoring and a reusable editor platform with documents, cursors, selections, markers, folding, symbols, diagnostics, completion, code actions, diff hunks and configuration.

The implementation is C23-first and keeps public Framework contracts independent of GTK4. GTK4 remains an adapter rather than a public ABI dependency.
