Umicom Framework & Applications

Build with Umicom Framework

Reusable C components, practical learning and desktop applications built on one shared foundation.

Start with the components your application needs

A note-taking application needs documents, commands, windows and a way to save work. A banking workstation needs many of the same facilities, alongside financial services. Umicom Framework is the shared C-first foundation from which these applications are assembled.

The application selects the components it needs. Framework owns reusable behaviour; the application supplies its identity and composition. Begin with a small Notes project, then follow the same boundaries as it gains an editor, menus, persistent state and background work.

Each worked topic links its public header, implementation, tests and example. Follow a call through the code, learn who owns the data, and use the supplied build target to try it yourself.

Master Controller / Slave Controller describes how work is delegated. A Slave Controller manages a defined area; it does not reach into another module's private state. Database access for Umicom-owned application state belongs behind the Data Server.
