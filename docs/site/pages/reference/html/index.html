API reference build instructions

The function and type index is generated from the real source, not invented by the website.

Generate the API reference from your checkout

The public website and worked Wiki pages are available. The full function/type/source index is generated separately by Doxygen; it has not been included in this site build yet.

Install Doxygen through your supported development toolchain, configure the documentation project again, then build umicom-website-api. Read Publishing the documentation for the commands. A missing generator produces a failed API target, not a successful but empty reference.

Meanwhile, use the searchable header catalogue to open the actual public interfaces and the worked Wiki topics for usage.
