Reading option risk observations

An option is a contract whose value depends on an underlying instrument. A broker may report estimates describing how that option's value responds to market changes. These estimates are called Greeks. They are observations from a model, not guaranteed prices or instructions to trade.

Open the observations

  1. Open Umicom Trader and choose the intended Paper or Live connection. Authenticate in your local TWS or IB Gateway application, including its second factor. Umicom does not collect that password.
  2. Open the broker connection window, enable the configured local socket endpoint and connect. Wait for the account connection to become ready. Keep broker API access read-only while checking observations.
  3. In the broker workspace, use Options to choose an explicit option candidate, or use the contract ID and exchange from its broker contract description. Confirm the contract on the Instrument page. An underlying share's contract ID identifies a different instrument.
  4. In Market data choose the data mode and Subscribe. Expand Option risk observations. Select Bid, Ask, Last or Model to see the independent calculations. Changing these tabs does not start another subscription.
  5. Inspect each value's availability and data type. Choose Stop quotes when finished. This stops the subscription; it does not cancel an order.

Understand the fields

FieldMeaning
Implied volatilityThe broker model's estimate of variability. Read the displayed return-based or price-based volatility basis before interpreting it.
DeltaA model estimate of how the option value changes with the underlying price.
GammaHow that delta changes as the underlying price changes.
VegaSensitivity to the model's volatility input.
ThetaSensitivity to the passage of time in the broker model.
Option price, dividends, underlying priceThe values supplied with that calculation. They retain the provider's units and decimal text.

Umicom does not convert these estimates into portfolio currency, percentages or position exposure. Read the provider's unit conventions before comparing different contracts. The four tabs are separate calculation bases; one tab receiving data does not make another tab current.

Missing and stale data

Not received means no value for that field has arrived. Unavailable means the broker supplied its not-computed marker. Neither means zero. A value becomes STALE after 15 seconds without another observation, after disconnection, or when its subscription or data type is no longer current. Delayed and frozen observations remain labelled even if recently received.

If values remain missing, check the option identity and broker permissions for both the option and its underlying. Inspect the connection diagnostic rather than repeatedly subscribing. A non-option instrument may have no option calculations. Reconnect explicitly after a connection failure; the new connection starts without the old subscription.

Follow the Framework source

The quote owner in src/ibkr_connection/quotes.c creates and cancels market-data subscriptions. option_computation.c decodes complete packets into bounded values owned by that same subscription. UmiIbkrQuoteCopy returns a copy and computes each field's age. The native workspace displays that copy; it does not open another socket or calculate synthetic Greeks.

The adapter supports the negotiated legacy field protocol, not protobuf packets. This view does not implement hypothetical option-price requests, portfolio risk calculation or order submission. Both the broker's market-data permissions and protocol compatibility must be checked on the installed environment.
