Read UTF-8 across model-output chunks

A local model or network connection can deliver text in pieces. A piece is a transport boundary, not necessarily a complete character. This lesson implements the small shared boundary which turns incoming bytes into complete UTF-8 scalars. It does not start an inference server or turn an existing HTTP client into a streaming client.

1. Separate bytes, scalars and displayed characters

UTF-8 encodes a Unicode scalar in one to four bytes. Surrogate code points are excluded. Overlong encodings and values above U+10FFFF are invalid. The authoritative byte ranges are in Unicode chapter 3, Table 3-7.

A scalar is not always a whole displayed character: combining marks and multi-scalar sequences can be rendered together. This helper handles encoding boundaries. It does not normalize text, measure glyphs, sanitize terminal controls or segment user-perceived characters.

2. Reassemble a split scalar

The euro sign is encoded as the bytes E2 82 AC. If a provider supplies E2 in one chunk and 82 AC in the next, displaying E2 immediately produces incomplete UTF-8. Keep the partial prefix in Framework state until a complete scalar is available.

#include "umicom/base/utf8_stream.h"

UmiUtf8Stream decoder = {0};
uint8_t output[4];
size_t produced = 0;

UmiStatus status = UmiUtf8StreamAppend(&decoder, 0xe2U,
    output, sizeof output, &produced);
/* status == OK, produced == 0: nothing is ready to publish. */
if (status == UMI_STATUS_OK)
    status = UmiUtf8StreamAppend(&decoder, 0x82U,
        output, sizeof output, &produced);
if (status == UMI_STATUS_OK)
    status = UmiUtf8StreamAppend(&decoder, 0xacU,
        output, sizeof output, &produced);
/* On OK, produced == 3 and output holds E2 82 AC. */

Always use the returned byte count. The output is a byte span, not a C string. U+0000 is a valid scalar and produces one zero byte. A higher-level text protocol may choose to reject embedded NUL separately.

3. Handle refusal without losing the prefix

If output capacity is too small for a complete scalar, Append returns CAPACITY_EXCEEDED and leaves the stream, output buffer and produced count unchanged. Retry the same input byte with sufficient output space. If the byte would make an impossible Unicode prefix, it returns PARSE_ERROR with the same preservation rule.

For example, E0 80 cannot become a valid three-byte scalar: its prefix already implies an overlong encoding. The implementation asks the existing UmiUtf8DecodeScalar to validate a minimally completed prefix. Unicode validity therefore has one owner in Base, shared with documents and evidence writers.

Initialize the stream with zero or Reset. A copy of the struct can stage a larger transaction: append to the copy, then assign it back only after the surrounding operation accepts the whole chunk. Serialize access to a given stream; this small value type contains no mutex.

4. Distinguish end-of-input from reset

Finish checks whether a scalar remains incomplete. It returns INVALID_STATE for an unfinished prefix without discarding that prefix. It is a completeness check, not a final-once lifecycle operation. A subsequent byte can complete the scalar. Reset deliberately clears pending bytes and counters.

Inspect copies completed scalar and byte counts plus the number of bytes still required. Counter exhaustion is refused before publication. These counts measure encoded data, not model tokens or rendered character widths.

5. Keep compatibility collection bounded

The older umi_ai_stream_push collector remains a NUL-terminated byte-string interface. Its struct layout and callback remain unchanged. It now validates its stored length, scans input only through the remaining capacity, and copies an accepted chunk before appending. This supports self-append and source slices without overlapping-copy undefined behavior.

The callback receives a chunk borrowed only for that call. It must copy text it wants to retain. A callback can reset the collector or append another chunk without changing the outer callback's borrowed text. The legacy final flag is still forwarded unchanged; that interface does not enforce request identity, Unicode validity or a single terminal event.

Do not use the compatibility collector as proof that a complete AI streaming workflow exists. Request/model identity, terminal state, cancellation, transport framing and application ownership require their own shared services and qualification.

6. Qualify the boundary

The existing scalar fixture now also checks invalid public state, counter exhaustion and output-preserving retry. A separate fixture reconstructs all 1,112,064 Unicode scalar values byte by byte. The collector fixture covers 14 scenarios, including bounded unterminated input, corrupt state, self-append and callback mutation.

cmake --build build/windows-ucrt64-debug --target umicom-utf8-stream-test umicom-utf8-stream-scalars-test umicom-ai-stream-collector-test
ctest --test-dir build/windows-ucrt64-debug -R "^framework\.(base\.utf8_stream|ai\.stream_collector\.)" --output-on-failure

Run commands separately and stop on errors. These are native runtime tests which still require execution; successful configuration only registers them. The all-scalar test checks encoding and incremental publication, not GUI font rendering or real model output.

Installed SDK clients include umicom/base/utf8_stream.h and link Umicom::base. The legacy collector is in Umicom::ai. Neither requires cloning Framework into the client source tree. Use the package's installed SDK validation helpers as shown in the existing independent examples.

Exercise

Feed E2 82, call Finish, then feed AC. Explain why Finish fails first and succeeds second. Next, retry AC with a two-byte output buffer and verify that the state and produced count are unchanged. Finally, decide where your application should reject embedded NUL and where it should reject an event for a retired model request.
