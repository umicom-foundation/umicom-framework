Build a document workflow with Model, View and Controller

A working note-taking application needs more than a text box. It must retain text, track whether it has changed, decide where to save it and protect a draft when the user asks for a new note. We will follow these responsibilities through the Notes model before attaching a graphical interface.

Identify the owners

The document store holds the working copy. The view model describes what the editor should display. The document coordinator keeps those representations connected and handles actions such as Save and Undo. The Notes wrapper supplies the application’s small set of commands.

This arrangement applies Model–View–Controller responsibilities without requiring C++ classes. The model owns state and rules. The view displays that state. A controller handles requests and coordinates the relevant services. In a larger Umicom application, the Master Controller supervises the application while bounded Slave Controllers own their modules.

Use an opaque handle

notes_model.h declares UmiLearningNotes without exposing its fields. Callers can hold a pointer and use the published functions, but cannot reach into the private store. This is an opaque handle. It helps prevent the GUI from becoming dependent on the model’s internal layout.

The create function acquires its resources in order. On failure it calls the same destroy function used during normal shutdown. The destroy function tolerates missing resources and releases the objects in the reverse dependency order. The coordinator must be destroyed before the store and workbench it borrows.

Edit and read back

UmiLearningNotesSetText updates a view-model snapshot and synchronises it through the coordinator. The coordinator keeps the previous text for Undo. The function rejects text beyond the view’s supported capacity rather than silently truncating a note.

UmiLearningNotesCopyText returns a separate text copy. The caller releases it with the matching Framework free function. This contract allows the window to refresh its buffer without retaining a pointer into mutable internal storage.

Protect an unfinished note

The New command examines the active document before replacing it. A nonempty unsaved draft is rejected. The user must save it or explicitly discard it. A successful New creates another empty working copy through the same coordinator.

The test first creates two drafts, checks that New is rejected, performs Undo and verifies the recovered text. It then saves, simulates an external modification and checks that the external file is not overwritten. These tests exercise the application through its public contract rather than changing private fields.

Design patterns in context

The command registry demonstrates Command. The GTK frontend will be an Adapter. Passing the model through a callback context is a simple form of dependency injection. The document store and coordinator provide a single owner for the working copy. Learn these patterns by tracing actual requests; memorising a diagram without following the data is less useful.

Build and run the supplied example

Configure the learning targets once using the course setup. Run the commands below one at a time. Stop when a command reports a failure; do not continue to run an older executable.

Windows · PowerShell

Set-Location "C:\umicom\Umicom-Applications"
$env:Path = "C:\msys64\ucrt64\bin;$env:Path"
cmake --build --preset windows-ucrt64-all-debug --target umicom-learning-notes-session --parallel 2
& ".\build\windows-ucrt64-all-debug\bin\umicom-learning-notes-session.exe"

Linux · terminal

cd "$HOME/umicom/Umicom-Applications"
cmake --build --preset linux-gcc-all-headless-debug --target umicom-learning-notes-session --parallel 2
./build/linux-gcc-all-headless-debug/bin/umicom-learning-notes-session

/*-----------------------------------------------------------------------------
 * Umicom Framework — application development lessons
 * File: examples/learning/projects/notes_model.h
 * PURPOSE: Compose document, view-model and command contracts for the Notes lessons.
 * AUTHOR AND ORGANISATION: Sammy Hegab, Umicom Foundation
 * LICENCE: MIT
 *---------------------------------------------------------------------------*/

#ifndef UMICOM_LEARNING_NOTES_MODEL_H
#define UMICOM_LEARNING_NOTES_MODEL_H
#include "umicom/base/status.h"
#include "umicom/document/coordinator.h"

/* An opaque handle: the GTK adapter does not own the store or its text. */
typedef struct UmiLearningNotes UmiLearningNotes;
UmiStatus UmiLearningNotesCreate(UmiLearningNotes **outNotes);
void UmiLearningNotesDestroy(UmiLearningNotes *notes);
UmiStatus UmiLearningNotesSetText(UmiLearningNotes *notes, const char *text);
/* Allocates a copy for the caller. Release it with umi_document_store_free_text. */
UmiStatus UmiLearningNotesCopyText(UmiLearningNotes *notes, char **outText);
UmiStatus UmiLearningNotesSnapshot(UmiLearningNotes *notes, UmiDocumentWorkingCopySnapshot *outState);
UmiStatus UmiLearningNotesExecute(UmiLearningNotes *notes, const char *command, const char *argument);
#endif
test_notes_model.c

framework/examples/learning/projects/test_notes_model.c

/*-----------------------------------------------------------------------------
 * Umicom Framework — application development lessons
 * File: examples/learning/projects/test_notes_model.c
 * PURPOSE: Check the real Notes model without requiring a graphical display.
 * AUTHOR AND ORGANISATION: Sammy Hegab, Umicom Foundation
 * LICENCE: MIT
 *---------------------------------------------------------------------------*/

#include "notes_model.h"
#include "umicom/platform/filesystem.h"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define CHECK(test) do { if (!(test)) { fprintf(stderr, "line %d: %s\n", __LINE__, #test); return EXIT_FAILURE; } } while (0)
int main(void)
{
    UmiLearningNotes *notes = NULL;
    char *text = NULL;
    UmiDocumentWorkingCopySnapshot state;
    CHECK(!umi_fs_exists("notes.txt"));
    CHECK(UmiLearningNotesCreate(&notes) == UMI_STATUS_OK);
    CHECK(UmiLearningNotesSetText(notes, "first draft\n") == UMI_STATUS_OK);
    CHECK(UmiLearningNotesSetText(notes, "second draft\n") == UMI_STATUS_OK);
    CHECK(UmiLearningNotesExecute(notes, "notes.new", NULL) == UMI_STATUS_INVALID_STATE);
    CHECK(UmiLearningNotesExecute(notes, "notes.undo", NULL) == UMI_STATUS_OK);
    CHECK(UmiLearningNotesCopyText(notes, &text) == UMI_STATUS_OK);
    CHECK(strcmp(text, "first draft\n") == 0); umi_document_store_free_text(text);
    CHECK(UmiLearningNotesExecute(notes, "notes.save", "notes.txt") == UMI_STATUS_OK);
    CHECK(UmiLearningNotesSnapshot(notes, &state) == UMI_STATUS_OK && !state.dirty);
    /* Deleting every character of a saved note is still an unsaved edit. */
    CHECK(UmiLearningNotesSetText(notes, "") == UMI_STATUS_OK);
    CHECK(UmiLearningNotesExecute(notes, "notes.new", NULL) == UMI_STATUS_INVALID_STATE);
    CHECK(UmiLearningNotesSetText(notes, "third draft\n") == UMI_STATUS_OK);
    CHECK(umi_fs_write_text("notes.txt", "external change\n") == UMI_STATUS_OK);
    CHECK(UmiLearningNotesExecute(notes, "notes.save", "notes.txt") == UMI_STATUS_INVALID_STATE);
    CHECK(umi_fs_read_text("notes.txt", &text, NULL) == UMI_STATUS_OK);
    CHECK(strcmp(text, "external change\n") == 0); umi_fs_free_text(text);
    CHECK(UmiLearningNotesExecute(notes, "missing.command", NULL) == UMI_STATUS_NOT_FOUND);
    UmiLearningNotesDestroy(notes); CHECK(remove("notes.txt") == 0);
    puts("Notes model checks passed."); return EXIT_SUCCESS;
}
