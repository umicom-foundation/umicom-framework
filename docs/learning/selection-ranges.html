Share syntax selections through source navigation

Selection ranges describe language structure without editing text. Framework uses the same owned location catalogue and document-owner navigation used by other source tools. Applications select an intent and present the result instead of implementing another parser or direct editor mutation.

  1. Capture source text and a byte offset at a valid character boundary. Set UmiLanguageNavigationRequest.kind to UMI_LANGUAGE_NAVIGATION_SELECTION_RANGES.
  2. Use UmiLanguageNavigationQueryNative with a configured local server, or UmiLanguageNavigationQueryOnServer with an exclusively owned starting server. Keep request text alive until the synchronous query returns.
  3. The query negotiates the independent selection-range capability and UTF-16 positions. It sends one position in textDocument/selectionRange, not a definition or reference request.
  4. Read returned catalogue rows in order. The first range contains the requested caret; every following parent contains the preceding range. Target and selection metadata contain the same exact range in the captured document.
  5. Before using a row in a UI, recheck its captured source request. Copy the borrowed URI before callbacks can destroy the catalogue.
  6. After explicit user selection, navigate through the document coordinator. This validates current text positions and changes selection without creating a text edit or saving.
  7. Destroy the location catalogue when its views are no longer needed.

Decode a response separately

UmiLanguageLocationCatalogueReadSelectionResponse validates a complete response identifier, document URI and requested UTF-16 position. A null result produces an empty catalogue. A non-null result must contain exactly one selection object for the one requested position. Each optional parent must be an object with an ordered range enclosing its child. Equal ranges and empty ranges at the caret are permitted.

The reader copies URI storage, walks parents iteratively, checks cancellation and publishes nothing on failure. Its limits are 64 ranges, one MiB of JSON, 131,072 nodes and 80 container levels. Unknown extension fields still consume those budgets. Native queries also have smaller transport limits and verify every returned range against the captured source, including exact Unicode boundaries.

Ownership and extension

Standalone decoding checks range structure but has no source text. Callers using that layer must resolve every coordinate before navigation. Native query results are withheld until document-close and server shutdown complete successfully. Input preflight failures leave an owned server untouched; started sessions are retired through the shared cleanup path.

A future interactive expand-selection command can use the same ordered ranges, but it must retain a source revision and invalidate the chain after text or caret changes. Do not infer current source identity from coordinates alone.
