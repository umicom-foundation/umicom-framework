Save a note without overwriting someone else’s work

A note stored only in memory disappears when its process ends. Saving gives it a place on disk. We will use the Notes command-line program to write a file, then examine the difference between a new destination and a file that already belongs to someone else.

Use a destination you can identify

Create a practice directory outside the application source tree. On Windows, a suitable location is C:\umicom\practice-notes. On Linux, use $HOME/umicom/practice-notes. You must be able to say where the file will be written before executing the save.

An absolute path starts from a filesystem root. A relative path starts from the process’s current working directory. The Notes model resolves its requested destination to an absolute path before comparing it with the current document path.

Run the Notes model

Build umicom-learning-notes-session using the commands below. Without an argument, it edits a note in memory, undoes the latest change and prints the remaining text. With one path argument, it also asks the notes.save command to save the note.

Umicom Notes: review the build.

Use a new filename for the first run. The model refuses to overwrite an unrelated existing file. A successful return means the save operation succeeded; a failure prints the status and returns a nonzero process exit code.

Follow the save boundary

The command handler resolves the path and reads the current document state. If this is the same file already opened by the document, it uses the coordinator’s normal Save operation. Otherwise it checks that the destination is new and uses Save As.

The coordinator owns the relationship between the working copy, its disk identity and its view. Its saver performs the file-writing work. The command-line frontend does not independently reopen the file and write bytes around the coordinator. That keeps the same conflict rules available to the graphical application.

Recognise an external change

Suppose another editor changes a note after we loaded it. Saving our older copy could erase that person’s work. The Framework coordinator compares the file with the version it originally loaded and reports a conflict rather than silently accepting the overwrite.

The included Notes model test deliberately creates this situation. It writes an external change, attempts to save a local draft and then confirms that the external text is still present. This is a behaviour worth testing, not just describing in a comment.

A mistake to avoid

/* Do not bypass the document owner to make an error disappear. */
FILE *file = fopen(path, "w");
/* Opening this way can truncate an existing file immediately. */

The problem is not that file APIs are forbidden. It is that this call bypasses the application’s chosen ownership and conflict policy. Low-level I/O belongs inside the service responsible for applying those rules.

Practise the failure path

Save a note to a new file and read it back with your usual editor. Run a fresh Notes session against the same destination. Explain why it refuses that destination rather than treating it as the previous session’s owned document.

Build and run the supplied example

Configure the learning targets once using the course setup. Run the commands below one at a time. Stop when a command reports a failure; do not continue to run an older executable.

Windows · PowerShell

Set-Location "C:\umicom\Umicom-Applications"
$env:Path = "C:\msys64\ucrt64\bin;$env:Path"
cmake --build --preset windows-ucrt64-all-debug --target umicom-learning-notes-session --parallel 2
& ".\build\windows-ucrt64-all-debug\bin\umicom-learning-notes-session.exe"

Linux · terminal

cd "$HOME/umicom/Umicom-Applications"
cmake --build --preset linux-gcc-all-headless-debug --target umicom-learning-notes-session --parallel 2
./build/linux-gcc-all-headless-debug/bin/umicom-learning-notes-session

notes_session.c

framework/examples/learning/projects/notes_session.c

/*-----------------------------------------------------------------------------
 * Umicom Framework — application development lessons
 * File: examples/learning/projects/notes_session.c
 * PURPOSE: Run the Notes model from a terminal using the same commands as its window.
 * AUTHOR AND ORGANISATION: Sammy Hegab, Umicom Foundation
 * LICENCE: MIT
 *---------------------------------------------------------------------------*/

#include "notes_model.h"
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char **argv)
{
    UmiLearningNotes *notes = NULL;
    char *text = NULL;
    UmiStatus status = UmiLearningNotesCreate(&notes);
    if (status == UMI_STATUS_OK) status = UmiLearningNotesSetText(notes, "Umicom Notes: review the build.\n");
    if (status == UMI_STATUS_OK) status = UmiLearningNotesSetText(notes, "Umicom Notes: review the build and tests.\n");
    if (status == UMI_STATUS_OK) status = UmiLearningNotesExecute(notes, "notes.undo", NULL);
    if (status == UMI_STATUS_OK) status = UmiLearningNotesCopyText(notes, &text);
    if (status == UMI_STATUS_OK) fputs(text, stdout);
    umi_document_store_free_text(text);
    if (status == UMI_STATUS_OK && argc == 2) status = UmiLearningNotesExecute(notes, "notes.save", argv[1]);
    if (status != UMI_STATUS_OK) fprintf(stderr, "Notes operation failed: %s\n", umi_status_text(status));
    UmiLearningNotesDestroy(notes);
    return status == UMI_STATUS_OK ? EXIT_SUCCESS : EXIT_FAILURE;
}
notes_model.c

framework/examples/learning/projects/notes_model.c

/*-----------------------------------------------------------------------------
 * Umicom Framework — application development lessons
 * File: examples/learning/projects/notes_model.c
 * PURPOSE: Reuse Framework documents and commands; keep GTK out of the model.
 * AUTHOR AND ORGANISATION: Sammy Hegab, Umicom Foundation
 * LICENCE: MIT
 *---------------------------------------------------------------------------*/

#include "notes_model.h"
#include "umicom/base/text.h"
#include "umicom/platform/filesystem.h"
#include <stdlib.h>
#include <string.h>

struct UmiLearningNotes {
    UmiCommandRegistry *commands;
    UmiUiWorkbench *workbench;
    UmiDocumentStore *store;
    UmiDocumentCoordinator *documents;
};

/* A save uses the coordinator's atomic writer and external-change checks. */
static UmiStatus SaveNote(void *context, const char *argument, char *message, size_t capacity)
{
    UmiLearningNotes *notes = context;
    UmiDocumentWorkingCopySnapshot state;
    char current[UMI_PATH_CAPACITY], destination[UMI_PATH_CAPACITY];
    UmiStatus status;
    (void)message; (void)capacity;
    if (argument == NULL || argument[0] == '\0') return UMI_STATUS_INVALID_ARGUMENT;
    status = umi_fs_current_directory(current, sizeof(current));
    if (status == UMI_STATUS_OK)
        status = umi_path_absolute(argument, current, destination, sizeof(destination));
    if (status != UMI_STATUS_OK) return status;
    status = umi_document_coordinator_active_snapshot(notes->documents, &state);
    if (status != UMI_STATUS_OK) return status;
    if (state.has_path && umi_path_equal(state.path, destination))
        return umi_document_coordinator_save_active(notes->documents);
    /* Do not overwrite an unrelated existing note in a beginner exercise. */
    if (umi_fs_exists(destination)) return UMI_STATUS_ALREADY_EXISTS;
    return umi_document_coordinator_save_active_as(notes->documents, destination);
}

static UmiStatus NewNote(void *context, const char *argument, char *message, size_t capacity)
{
    UmiLearningNotes *notes = context;
    UmiDocumentWorkingCopySnapshot state;
    UmiStatus status = umi_document_coordinator_active_snapshot(notes->documents, &state);
    (void)argument; (void)message; (void)capacity;
    if (status == UMI_STATUS_OK) {
        if (state.dirty && (state.has_path || state.text_length != 0U)) return UMI_STATUS_INVALID_STATE;
        status = umi_document_coordinator_close_active(notes->documents, 1);
        if (status != UMI_STATUS_OK) return status;
    } else if (status != UMI_STATUS_NOT_FOUND) return status;
    return umi_document_coordinator_new(notes->documents, "UmicomNote.txt", NULL, 0U);
}

static UmiStatus UndoNote(void *context, const char *argument, char *message, size_t capacity)
{
    UmiLearningNotes *notes = context;
    (void)argument; (void)message; (void)capacity;
    return umi_document_coordinator_undo(notes->documents);
}

UmiStatus UmiLearningNotesCreate(UmiLearningNotes **outNotes)
{
    UmiLearningNotes *notes;
    UmiStatus status;
    if (outNotes == NULL) return UMI_STATUS_INVALID_ARGUMENT;
    *outNotes = NULL;
    notes = calloc(1U, sizeof(*notes));
    if (notes == NULL) return UMI_STATUS_OUT_OF_MEMORY;
    status = umi_command_registry_create(&notes->commands);
    if (status == UMI_STATUS_OK)
        status = umi_ui_workbench_create("learning.notes", notes->commands, &notes->workbench);
    if (status == UMI_STATUS_OK) status = umi_document_store_create(&notes->store);
    if (status == UMI_STATUS_OK)
        status = umi_document_coordinator_create(notes->store, notes->workbench, NULL, &notes->documents);
    UmiCommandDescriptor commands[] = {
        {sizeof(UmiCommandDescriptor), "notes.new", "New Note", "File", "Create an empty note without discarding changes.", "", UMI_COMMAND_MUTATES_STATE, NewNote, NULL, notes},
        {sizeof(UmiCommandDescriptor), "notes.save", "Save Note", "File", "Save through the Framework document coordinator.", "", UMI_COMMAND_MUTATES_STATE, SaveNote, NULL, notes},
        {sizeof(UmiCommandDescriptor), "notes.undo", "Undo", "Edit", "Restore the previous document text.", "", UMI_COMMAND_MUTATES_STATE, UndoNote, NULL, notes}
    };
    for (size_t index = 0U; status == UMI_STATUS_OK && index < sizeof(commands)/sizeof(commands[0]); ++index)
        status = umi_command_registry_register(notes->commands, &commands[index]);
    if (status == UMI_STATUS_OK) status = NewNote(notes, NULL, NULL, 0U);
    if (status != UMI_STATUS_OK) { UmiLearningNotesDestroy(notes); return status; }
    *outNotes = notes;
    return UMI_STATUS_OK;
}

void UmiLearningNotesDestroy(UmiLearningNotes *notes)
{
    if (notes == NULL) return;
    umi_document_coordinator_destroy(notes->documents);
    umi_document_store_destroy(notes->store);
    umi_ui_workbench_destroy(notes->workbench);
    umi_command_registry_destroy(notes->commands);
    free(notes);
}

UmiStatus UmiLearningNotesSetText(UmiLearningNotes *notes, const char *text)
{
    UmiDocumentWorkingCopySnapshot state;
    UmiUiDocumentViewSnapshot *view;
    UmiStatus status;
    if (notes == NULL || text == NULL) return UMI_STATUS_INVALID_ARGUMENT;
    if (strlen(text) >= UMI_UI_DOCUMENT_CONTENT_CAPACITY) return UMI_STATUS_CAPACITY_EXCEEDED;
    status = UmiLearningNotesSnapshot(notes, &state);
    if (status != UMI_STATUS_OK) return status;
    view = calloc(1U, sizeof(*view));
    if (view == NULL) return UMI_STATUS_OUT_OF_MEMORY;
    status = umi_ui_document_view_model_find(umi_ui_workbench_documents(notes->workbench), state.view_id, view);
    if (status == UMI_STATUS_OK) status = umi_text_copy(view->source_text, sizeof(view->source_text), text);
    if (status == UMI_STATUS_OK) {
        view->dirty = 1;
        status = umi_ui_document_view_model_upsert(umi_ui_workbench_documents(notes->workbench), view);
    }
    if (status == UMI_STATUS_OK) status = umi_document_coordinator_sync_active(notes->documents);
    free(view);
    return status;
}

UmiStatus UmiLearningNotesCopyText(UmiLearningNotes *notes, char **outText)
{
    UmiDocumentWorkingCopySnapshot state;
    if (notes == NULL || outText == NULL) return UMI_STATUS_INVALID_ARGUMENT;
    *outText = NULL;
    UmiStatus status = UmiLearningNotesSnapshot(notes, &state);
    return status == UMI_STATUS_OK ? umi_document_store_copy_text(notes->store, state.document_id, outText, NULL) : status;
}

UmiStatus UmiLearningNotesSnapshot(UmiLearningNotes *notes, UmiDocumentWorkingCopySnapshot *outState)
{
    return notes != NULL ? umi_document_coordinator_active_snapshot(notes->documents, outState) : UMI_STATUS_INVALID_ARGUMENT;
}

UmiStatus UmiLearningNotesExecute(UmiLearningNotes *notes, const char *command, const char *argument)
{
    return notes != NULL ? umi_command_registry_execute(notes->commands, command, argument, NULL, 0U) : UMI_STATUS_INVALID_ARGUMENT;
}
