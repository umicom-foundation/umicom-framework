Find a guide, then try its project

Start with the C, Assembly and Framework practicum. Then choose a product workflow that interests you. Each guide explains its own prerequisites and limits.

This catalogue does not mark lessons read, grant quiz credit or prove that a feature works on your computer. The links are local: keep this index beside the supplied guides. A missing file means that guide is not installed in this copy.

Use your browser's Find command to search this page. The native umicom-study library TERM command searches the same catalogue without opening files.
