Group existing GTK actions with local search

The action-menu service organizes existing GTK buttons. It does not create a second command dispatcher, retain an application controller, or replace the callbacks that already implement an action. Applications can use it for editor tools, drawing tools or other bounded groups of commands.

  1. Link Umicom::ui_gtk4 and include umicom/ui/gtk4/action_menu.h. Call UmiGtk4ActionMenuCreate with a readable label and an output widget pointer.
  2. Parent the returned menu button, or use g_object_ref_sink if you need to own it before parenting. These are normal GTK widget ownership rules: a new floating reference is transferred to its first parent.
  3. Create and bind each action button using your existing handler. Pass an unparented button and optional descriptive keywords to UmiGtk4ActionMenuAppend. The same button is adopted; its identity, sensitivity, tooltip and callbacks remain available.
  4. Users filter through the menu entry. A host may call UmiGtk4ActionMenuSetFilter or borrow the entry with UmiGtk4ActionMenuFilterEntry to add its own automation identity or focus it.
  5. Let the GTK main loop process queued filtering before inspecting UmiGtk4ActionMenuVisibleCount. Repeated typing is coalesced. An empty query reveals every action whose host-controlled visibility is enabled.
  6. Release the menu through normal GTK ownership when its host closes. Pending filtering keeps only a weak reference to the menu, so it cannot keep a retired application alive.

What is preserved

Search copies each label and its keywords when the action is appended. It normalizes Unicode and folds case before comparing a substring. Later changes to button sensitivity and visibility are respected. Action callbacks continue to belong to the application or shared document service that originally bound them; those owners must maintain their own lifetime checks.

A retained list widget keeps its independent filter context alive. Retained entry controls cannot queue work against a finalized menu. Replacing the service's popover is unsupported and retires public access safely. The host must not reparent internal rows or children. Build a fresh group if copied labels or keyword metadata need to change.

Limits and extension

A group accepts at most 256 buttons. Captions are limited to 512 UTF-8 bytes, keywords to 2,048 bytes, and queries to 1,024 bytes and 256 Unicode characters. Invalid input is refused before adoption or field updates. Initial append validation failure leaves an unparented button with its caller; normal GTK floating-reference rules still apply.

Keep action execution explicit. Filtering and the entry's Enter key do not invoke the first result. Add new action descriptors in a host's grouping list while retaining the original button construction and lifetime binding. This allows the shared service to improve presentation without moving application behavior into a second UI implementation.

Show a command's keyboard shortcut

A shortcut is a key combination such as Ctrl+S. Use UmiGtk4ActionMenuButtonCreate to place the caption on the reading edge and a native GTK shortcut label on the other edge. Supply the same key and modifier flags that your keyboard handler uses. The function creates presentation; it does not install a keyboard handler or grant permission to execute a command.

GtkWidget *save = NULL;
UmiStatus status = UmiGtk4ActionMenuButtonCreate(
    "Save", GDK_KEY_s, GDK_CONTROL_MASK, &save);
if (status == UMI_STATUS_OK) {
    /* Bind the existing Save handler and its lifetime guard here. */
    UmiStatus appended = UmiGtk4ActionMenuAppend(menu, save, "write document");
    if (appended != UMI_STATUS_OK) {
        g_object_ref_sink(save);
        g_object_unref(save);
    }
}
  1. Pass zero for both key and modifiers when the command has no shortcut. Do not invent a shortcut merely to fill a menu row.
  2. Keep the button's sensitivity connected to command availability. A displayed shortcut must not bypass workspace trust, document state or pending-operation checks.
  3. Use the returned button directly in a normal GTK box, or append it to an action menu. Both paths retain its existing activation callback.
  4. Keep the generated row intact. Search copies its caption during append. To change a group of labels, construct a new group; replacing the child before append is rejected unless it becomes an ordinary labelled GTK button.

The output is a floating GTK widget. Failed validation clears the output pointer. An empty or invalid UTF-8 caption, a caption over 512 bytes, an invalid accelerator, or modifiers without a key are refused.
