Words used in this wiki

Source code
Text describing a program's instructions.
Compiler
A program that translates source into another executable representation.
Header
A file declaring interfaces used by other source files.
Function
A named group of operations that can receive inputs and return a result.
Pointer
A C value referring to an object or function; valid use depends on its target and lifetime.
Contract
The input, result, ownership and failure rules callers may rely on.
Library
Reusable compiled code linked into or loaded by another program.
SDK
Headers, libraries and supporting information used to build software against a platform.
Callback
A function supplied for another component to invoke when an event occurs.
Owner thread
The thread responsible for serialized access to an object; GTK widget work belongs on the GTK thread.
Manifest
Data describing a package and its resources.
Digest
A value computed from bytes to detect a change; not a publisher's signature.
Regression
A behaviour that worked before but fails after a change.
Content module
A declared collection of reading material; it does not grant permission to execute code.
