Your first C program

A source file is a text file containing instructions written in a programming language. C is one such language. A compiler translates those instructions into code that a computer can execute. Reading a source file does not run it.

Read the whole example

#include <stdio.h>

int main(void)
{
    puts("Hello from Bits2Banking.");
    return 0;
}

main names the function where this program starts. A function is a named group of instructions. The braces enclose its body. puts displays the quoted text and a new line. return 0 finishes and reports success; it does not print zero.

stdio.h describes standard input and output functions to the compiler. The #include line makes those declarations available. The semicolons end the two instructions inside the function.

Predict the output

Hello from Bits2Banking.

Change only the quoted text to “I am learning C.” What line should appear? The function name and success result remain unchanged. This example is in labs/native/first-c-programs/hello.c in Bits2Banking.
