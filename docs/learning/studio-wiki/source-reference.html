Find the implementation

A header states an interface. A source file implements it. A test calls the interface with chosen inputs and checks the result. Start with a small group of related files rather than trying to read the whole repository at once.

Follow one function

Find UmiLearningModuleOpen in the public header, then its definition. Notice that failure clears the output handles, while the input shelf remains unchanged. Follow the reader construction call to see where resource bytes are verified. Finally read the module tests and predict the result of a changed lesson file.

This map covers the examples in this wiki. For another component, find its public header, owning build target, implementation and tests together. Do not assume that a similarly named file in another checkout is the same revision.
