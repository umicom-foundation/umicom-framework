Introduction to Umicom Framework

Umicom Framework is a collection of reusable software services. An application supplies its own screens and workflow, while shared services handle work such as documents, commands and learning content. This wiki introduces those ideas through one small program.

Choose a starting point

  1. If source code is new to you, read Your first C program. Continue with the full Learning C course before studying pointer ownership.
  2. Read How the Framework fits an application.
  3. Follow Configure, build, test and run.
  4. Learn how a button reaches a shared function.
  5. Then explore extending Studio and authoring a content module.

Read with the source

The source map identifies the headers, implementations and tests used here. It is an introduction to selected components, not a complete reference for every Framework function. The glossary explains recurring terms.

Read one page at a time, predict the example's result, then compare it with the code. Use the Bits2Banking courses for longer exercises. Opening this wiki does not run examples or install tools.
