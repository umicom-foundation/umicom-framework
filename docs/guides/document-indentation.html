Choose indentation for one document

Indentation controls what Tab inserts and how tab characters are displayed. A document override applies to one open working copy. Other files continue to use their own overrides or the session defaults.

Use the native editor

  1. Open a source file or create an untitled document.
  2. Open Document indentation in the editor actions. The form names the captured document. Switching tabs does not change that target.
  3. Enter a whole tab width from 1 to 16. Select whether Tab inserts spaces, then choose Apply to this document.
  4. Press Tab at a caret or with a selection. A selection indents complete lines; Shift+Tab removes one level. Undo reverses text edits.
  5. Choose Use session defaults to remove the override. The message reports the effective setting. The controls remain your editable draft; clearing the override does not silently rewrite those controls.

Applying a preference does not reformat existing text, mark it dirty, save a file or add an Undo entry. The override lasts until the working copy closes. It is not currently saved in a project or user settings file.

Use the shared C API

#include <umicom/document/indentation_override.h>
UmiDocumentIndentationReview review;
UmiStatus status = UmiDocumentCoordinatorInspectIndentation(documents, id, &review);
if (status == UMI_STATUS_OK) {
    UmiEditorIndentation choice = {2U, 1};
    status = UmiDocumentCoordinatorApplyIndentation(documents, &review, &choice, NULL);
}

The review belongs to a live coordinator and a named document. Keep the coordinator alive, use its owning thread, and do not serialize the review. Pass NULL instead of a choice to inherit session defaults. A stale review is rejected even when the requested pair happens to match current values.

Recover from a rejected change

  • Settings changed elsewhere: close and reopen the form. Review the current pair before applying.
  • Document closed: open its file again and capture the new working copy.
  • Document operation busy: finish saving, reloading or navigation, then retry.
  • Refresh interrupted: the setting may already have applied. The message distinguishes that outcome. Refresh the editor display; do not assume source or preferences were rolled back.

Read-only source can have a different display policy, but text editing remains blocked. Tab width describes logical columns, not proportional-font character cells. Independent tab and indentation widths are not yet supported. The EditorConfig inspector remains a review tool; it does not automatically apply these settings.
