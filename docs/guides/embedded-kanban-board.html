Embedding a local Kanban board

The native board window owns one document, its unsaved changes and its file operations. A dock moves that window's existing controls into another native window. It does not open a second copy of the file or create a second editable board.

Add a dock to a GTK4 host

  1. Create a board with UmiKanbanGtk4CreateWindow or UmiKanbanGtk4CreateProjectWindow. Keep its window referenced while using it.
  2. Call UmiKanbanGtk4DockWindow(host, board, &pane) on the GTK owner thread. Both windows must belong to the same application. The call refuses a board that is already docked or has a pending file operation.
  3. Add the returned pane to the host's layout. The pane has an owned, nonfloating reference; release that reference when your host no longer needs it.
  4. Use UmiKanbanGtk4Undock(pane, true) to return the controls to their original window. This does not save, discard or close the document.
  5. Use UmiKanbanGtk4PresentWindow(board) when a launcher needs to show an existing board. It first returns docked contents, so the launcher cannot show an empty backing window.

Ownership and closing

Hiding or moving a layout pane keeps its board open. Removing the host window or releasing the pane returns the board to its independent window and presents it. The user can continue editing or save there. A pending save continues under the original board owner.

Request normal board closure with gtk_window_close(). The existing document guard refuses unsaved changes unless the user explicitly chooses to discard them. Forcing board destruction or terminating the process cannot preserve unsaved memory.

Project and publication boundaries

A project board retains the project identity captured when it was created. Changing the host's project does not retarget its open board. Private storage remains an explicit choice. Docking does not remember a location, write a file, evaluate code, start a server or publish a website.

Refused operations

BUSY means a file operation or native transfer is in progress. Finish it and try again. ALREADY_EXISTS means the board is in another dock; return it before moving it. CANCELLED means a window was removed during the operation. Keep existing documents and inspect their independent windows instead of reopening the same file blindly.
