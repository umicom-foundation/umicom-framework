Inspect a source draft

Source inspection counts the complete visible editor text and the selected range. It creates a separate, read-only observation. It does not read the saved file, save changes, move the caret or add an Undo entry.

  1. Open or create a text document. Select text if you also want selection counts.
  2. Choose Inspect source in Studio's editor controls.
  3. Compare the Document and Selection columns. The window retains these values even if you edit the source later.
  4. Review any invisible-character locations. Close the window and inspect again to observe a later draft.

Understand the counts

UTF-8 bytes measure editor text storage. Unicode scalars count encoded characters, while UTF-16 units match many language-server position conventions. A visible glyph may contain several scalars. Words here are runs separated by ASCII whitespace; this is not a natural-language word counter.

LF, CRLF and CR are counted separately. Empty text has one logical line, and a final newline adds an empty last line. Blank lines and trailing whitespace use ASCII spaces and tabs. A zero-length selection is empty text, with one logical line.

Invisible characters

The list shows bidirectional controls, selected zero-width characters, nonbreaking spaces and control characters as escaped codepoints. Locations use one-based lines and scalar columns, and zero-based byte offsets. These can be intentional, especially in international text; a notice does not prove malicious code. This is not a complete Unicode security analysis.

Framework integration

Capture with UmiDocumentCoordinatorInspectText, read metadata with UmiDocumentInspectionInfoRead, and borrow its analysis with UmiDocumentInspectionText. Destroy the document inspection once all readers finish. Independent tools can call UmiEditorTextInspectionCreate directly. Neither API performs file or network I/O.

Limits and recovery

The inspector accepts at most 8 MiB of valid UTF-8 without NUL bytes. It refuses endpoints inside a scalar or CRLF. The first 4,096 notices are listed; total counts still cover the complete source. If a document closes during construction, retry from an open document. No source changes are made on failure. Large or malformed documents require another inspection tool; they are not silently truncated.
