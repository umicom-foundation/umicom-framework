Comment source lines

Framework can add or remove a line-comment prefix selected from a document's language. Studio exposes this through Toggle language comment. The explicit Toggle // comment command remains available and keeps its existing shortcut.

  1. Open a source file. Its filename determines the initial language. CMakeLists.txt and Makefile are recognised as project files.
  2. Place the caret on a line, or select the lines you want to change.
  3. Choose Toggle language comment. C and related languages use //; Python, shell, CMake and similar configuration files use #; SQL and Lua use --; INI uses ;.
  4. Inspect the result before saving. Use Undo to restore the previous text and selection.

Behaviour and limits

One invocation changes one document through its existing editing history. If every nonblank selected line already has the chosen prefix, the command removes it; otherwise it adds the prefix to the selected lines. Blank lines are retained. Read-only documents cannot be changed.

This action uses literal line prefixes; it does not parse string literals, multiline strings, shebang lines, SQL dialects, embedded languages or conditional compilation. Select appropriate lines and review them. JSON, HTML, CSS, Markdown, plain text and generic Assembly have no guessed line syntax. The language-aware command is unavailable for those languages.

Embedding Framework

Use UmiDocumentCoordinatorLineCommentStyle to query a named document's language policy, and UmiDocumentCoordinatorToggleLanguageComment for a headless edit. GTK hosts dispatch UMI_DOCUMENT_COMMAND_TOGGLE_LANGUAGE_COMMENT through UmiGtk4AdapterDocumentCommand. They should query availability again when updating their controls. A completion callback may retire the host, so treat the call as the last use of a borrowed UI owner.

The style catalogue is immutable shared data. Hosts must not free or modify its returned descriptors. Unknown language IDs leave output pointers unchanged. No command saves the document or accesses the clipboard.
