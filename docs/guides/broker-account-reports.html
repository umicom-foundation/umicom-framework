Inspect TWS account reports

The Interactive Brokers connection inspector can request an account overview, balances and margin, or cash fields for one currency. It uses the existing read-only TWS or IB Gateway session and preserves provider numbers as text.

  1. Sign in to TWS or IB Gateway and complete its authentication. Enable the read-only socket API and verify the configured port and client ID.
  2. Open Trader’s Interactive Brokers connection window. Select your intended Paper or Live environment and connect. Confirm the actual environment in the provider application; the port alone does not establish it.
  3. Choose an account returned by the connection. Select Account overview, Balances and margin, or Cash in one currency. For the currency report, enter an uppercase three-letter currency such as GBP or USD.
  4. Select Read selected account once. Wait for the account-summary and position completion markers. These arrive independently; they do not form one atomic portfolio snapshot.
  5. Inspect the received fields, including their currency. Use Write new account report to save them with their timestamps and completeness flags. To request another report or account, disconnect and reconnect.

What each report requests

  • Overview: net liquidation, total cash value, buying power and available funds.
  • Balances and margin: account type, settled and accrued cash, equity, current and full margin requirements, excess liquidity, look-ahead requirements, severity and related account-summary fields.
  • Cash in one currency: the documented $LEDGER:CURRENCY request. ALL is refused because the provider gives that keyword aggregate semantics.

Only responses for the selected account and current request are retained. A missing field is not zero. The bounded inspector retains at most 64 account values and 64 positions; an over-capacity response stops inspection rather than presenting a truncated portfolio as complete.

Account summaries are provider observations, not bank statements or transfer instructions. The existing position and chart tools remain available, but this report does not calculate portfolio performance from incomplete history or authorise orders.

If the provider rejects the request, inspect its message and verify account permissions in TWS. Reconnect after correcting the cause. Do not reinterpret an empty or failed response as an available cash balance.

For contributors

UmiIbkrConnectionReadAccountReport validates the report choice, then uses the same request IDs, account filter, queue bounds and completion decoder as the established connection owner. The original UmiIbkrConnectionReadAccount API remains available. New report kinds must define a bounded documented tag list and regression coverage for wire encoding, account filtering and failure rollback.

References: IBKR account-summary API and TWS Account Window guide.
