Choose a document language

Framework infers a language from a source filename. A session override lets an editor identify an untitled file or unusual extension without renaming or rewriting it.

  1. Open a source document and choose Document language.
  2. Select a language. Choosing an item alone changes nothing.
  3. Choose Apply to this document. The form keeps its original document even if you switch tabs.
  4. Choose Use filename detection to remove the override. Close the form to leave the current policy unchanged.

The policy lasts until the document closes. It survives typing, Undo, Redo and Save As; it is not stored in the source file or saved across sessions. Read-only files can use a different display language. Changing language does not change text, selection, dirty state or history.

What language selection provides

It supplies one consistent identity to the native syntax display, language-aware line comments and future language-service requests. Installed syntax definitions and language servers remain separate dependencies. Choosing a language does not install or start a compiler or server. Previously captured language-service observations may become stale; explicitly restart live diagnostics when needed.

Embedding Framework

Use UmiDocumentLanguageChoiceCount/At to populate choices, then inspect a named document with UmiDocumentCoordinatorInspectLanguage. Pass that observation to UmiDocumentCoordinatorApplyLanguage. A null language ID restores detection. The service refuses changed filenames, replaced documents or stale policy revisions without writing any text.

GTK hosts can use UmiGtk4AdapterReviewDocumentLanguage or the standalone UmiGtk4LanguageChoiceCreate dropdown. Use these APIs on the owner thread. Keep a coordinator alive while holding a headless review; native forms instead resolve the existing weak editing binding before applying.

Troubleshooting

If a review reports a changed filename or policy, close and reopen it. If an editing operation is busy, complete it first. A closed document cannot be replaced by another tab with the same name. An unsupported language ID is rejected; plain text is an explicit supported choice.
