Replace within a source selection

A selection is the text you highlight in an editor. This operation replaces complete literal matches inside that captured selection. The surrounding document is kept unchanged.

Use the review

  1. Select the text to edit in a writable document.
  2. Enter the Find and Replace text and choose the case and whole-word settings.
  3. Open Replace in selection. The proposed text is filled in; the source has not changed.
  4. Choose Preview complete draft and inspect the complete before and after document.
  5. Approve the displayed edit, then choose Apply reviewed replacement. Undo restores the prior draft. Saving remains a separate action.

Shared C API

UmiDocumentPrepareSelectionReplacement creates an owned UmiDocumentProposal. Use its inspect, text, check, apply and destroy operations. Apply requires the reviewed proposal revision and explicit approval. Preparation does not save, synchronize or add history.

UmiDocumentProposal *proposal = NULL;
size_t matches = 0;
UmiStatus status = UmiDocumentPrepareSelectionReplacement(
    documents, document_id, "old", "new", NULL, &proposal, &matches);
/* Inspect and approve the result before calling Apply. */
UmiDocumentProposalDestroy(proposal);

UmiEditorSearchReplaceRangeSize and UmiEditorSearchReplaceRange are the reusable byte-oriented layer. The offset and span must fit the complete input. Output is the complete document, including its unchanged prefix and suffix. Measure first; allocate one additional byte for the terminating zero. Input/output overlap is rejected.

Boundaries and limits

Matching is literal, with exact case, ASCII-insensitive or smart-case options. Whole-word checks include the neighboring characters outside the selected range, so selecting cat inside scatter does not make it a whole word. Only complete, nonoverlapping original matches are replaced. Replacement text is not searched again. Match-list limits do not truncate replacements.

The document layer requires UTF-8 text and selection boundaries that do not split a character or a CRLF line ending. Empty selections are rejected. No match produces an unchanged review. Editing the captured source invalidates the proposal; opening another tab does not redirect it. A proposal belongs to its original coordinator and is not a file-writing or network operation.

Recovery

If the review says the source changed, cancel and create a new review from the current selection. If Apply is unavailable, preview the latest proposed text and approve it again. Read-only documents must be made writable through the document owner before editing. Native tests require an available GTK display; a skipped native test is not a pass.
