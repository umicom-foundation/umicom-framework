Convert selected ASCII letters

Studio can change the case of selected letters without changing the rest of the document. ASCII letters are the English letters A–Z and a–z. Accented letters, other writing systems, emoji, numbers and punctuation remain unchanged.

In Studio

  1. Open a writable text document and select the characters to change.
  2. Open Code tools. Type selection case in its filter.
  3. Choose Uppercase selected ASCII letters or Lowercase selected ASCII letters.
  4. Inspect the selected replacement. For example, selecting abc inside xabcx and choosing uppercase produces xABCx. The surrounding letters are not changed.
  5. Use Undo to restore the draft, or Save when you want to write it to disk.

Conversion is one document edit. It keeps the exact selection and participates in the same Undo and Redo history as other document commands. It does not save the file automatically.

Shared Framework use

Applications can register the canonical commands umicom.document.line-edit.uppercase-selection and umicom.document.line-edit.lowercase-selection through umi_document_commands_register. These commands read the current draft and selection; they do not accept a file path or offsets as an argument.

Clients preparing a preview without changing a document can use UmiEditorLineEditPlanCreate with UMI_EDITOR_EDIT_COMMAND_TRANSFORM_UPPERCASE or UMI_EDITOR_EDIT_COMMAND_TRANSFORM_LOWERCASE. The plan owns its output until destroyed. Use the document coordinator to apply the result so that document identity and history remain authoritative.

If a command is unavailable

  • Select text first. An empty selection is refused; it does not convert the entire file.
  • Use a writable document. Read-only documents remain unchanged.
  • Finish any pending edit review before applying another command.
  • The document facade accepts valid UTF-8 text up to 8 MiB and LF or CRLF line endings. A selection may not split a UTF-8 character. Bare CR line endings are currently unsupported.
  • Already converted text makes no new Undo entry. This is a successful unchanged result.

This is explicit ASCII conversion, not language-sensitive Unicode casing. For example, uppercasing café produces CAFé. It does not rename symbols, update references, infer capitalization rules or format source code.
